Como seus dados são salvos

Seus dados ficam com você. Simples assim.

O VULP+ usa o armazenamento local do seu navegador (localStorage) para guardar suas informações. Entenda o que isso significa na prática — e como manter tudo seguro.

Pense em uma gaveta do seu navegador.

Tudo o que você anota no VULP+ — disciplinas, planejamento, questões e desempenho — fica guardado nessa gaveta, dentro do seu próprio dispositivo.

O localStorage é um recurso do navegador que permite guardar informações no seu computador, tablet ou celular, sem enviá-las para um servidor externo.

Na prática, isso significa que:

  • Seus dados são salvos automaticamente enquanto você usa a plataforma.
  • Nada é enviado para a nuvem ou para terceiros.
  • Você não precisa criar uma conta em um servidor para usar o sistema.
  • O acesso é rápido, pois as informações já estão no seu dispositivo.

Privacidade

Suas informações não saem do seu dispositivo. Não há envio para servidores externos.

Controle

Você pode exportar e importar seus dados quando quiser, mantendo uma cópia de segurança.

Velocidade

Como os dados já estão no dispositivo, o acesso é rápido e direto.

Sem custo

Não há servidor de armazenamento envolvido — por isso o acesso é gratuito.

Atenção: como os dados ficam salvos no navegador, se você limpar o cache ou os dados do navegador, ou trocar de dispositivo, eles não estarão automaticamente disponíveis. Por isso, use a função de backup sempre que quiser guardar uma cópia.
  1. 1
    Acesse a plataforma pelo navegador

    Use o Chrome, Firefox, Edge, Safari ou outro navegador moderno — no computador, tablet ou celular.

  2. 2
    Use normalmente

    Tudo o que você cadastrar é salvo automaticamente no armazenamento local do navegador. Você pode fechar a aba e voltar depois.

  3. 3
    Exporte um backup periodicamente

    Na área de backup da plataforma, exporte uma cópia dos seus dados. Guarde o arquivo em um local seguro.

  4. 4
    Para usar em outro dispositivo, importe o backup

    Ao acessar de outro computador, tablet ou celular, use a opção de importar o arquivo de backup para recuperar seus dados.

  5. 5
    Evite limpar os dados do navegador sem antes exportar

    Se precisar limpar o cache ou os dados do navegador, exporte um backup antes para não perder suas informações.
